# Darwin core terms

Used internally by
[`vert_id()`](https://docs.ropensci.org/rvertnet/reference/vert_id.md)
to filter data to Darwin core terms only. Get in touch with us if these
terms need correcting or are out of date.

## Usage

``` r
simple_dwc_terms
```

## Format

### `simple_dwc_terms`

A character vector
